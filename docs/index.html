隐私政策

适用于 Apple Watch App「组间」

生效及最后更新日期：2026 年 9 月 1 日

简单来说：「组间」没有用户账号、广告、跟踪或开发者服务器。动作与健康数据仅在你的设备上处理，不会发送给开发者或出售给任何第三方。

1. 本政策的适用范围

本隐私政策说明「组间」在提供自动组间休息计时、训练记录和 Apple Watch 小组件功能时，如何处理信息。本政策仅适用于「组间」正式发布版本。

2. 我们处理的信息

手腕运动数据

训练期间，「组间」会通过 Core Motion 读取手腕的加速度、旋转速度及姿态相关数据，用于在设备上判断一组训练何时开始和结束。这些原始动作数据仅进行实时、短暂处理，不写入训练历史，也不会发送到开发者服务器。

健康与体能训练数据

「组间」使用 HealthKit 启动力量训练会话，以便在息屏或后台期间稳定运行。App 会请求：

  • 体能训练写入权限：用于启动和管理训练会话，是开始训练所必需的权限。
  • 心率读取权限：用于在训练期间计算每组的平均心率和最高心率。该权限是可选的；拒绝后，自动检测和休息计时仍可使用。

训练结束时，「组间」会丢弃 Workout Builder 中的完整训练，不由本 App 向“健康”App 保存一条完整训练记录。但 Apple 系统在训练会话期间生成或管理的底层健康样本，仍可能依据 HealthKit 和“健康”App 的系统规则留存；这些数据由 Apple 和用户的健康权限设置控制。

本地训练记录与设置

「组间」会在设备本地保存默认休息时长，以及整场训练和每组的开始时间、结束时间、暂停时长、组数、平均心率和最高心率。若没有心率权限，相应心率数据不会被记录。

为了显示表盘复杂功能和智能叠放组件，App 与小组件会通过本地 App Group 共享当前训练状态、组数和休息倒计时等必要状态。这些信息不会离开设备。

3. 数据是否会发送或共享

「组间」正式版本不包含广告、第三方分析 SDK、跨 App 跟踪或开发者运营的数据服务器。我们不会将你的动作数据、心率、训练记录或设置发送给开发者、出售给他人，或用于广告与用户画像。

HealthKit 和 watchOS 系统功能由 Apple 提供，并受 Apple 的隐私政策及用户授权设置约束。

4. 数据保存与删除

训练记录和设置会保存在你的设备上，直到你主动删除。你可以在“训练记录”中删除单次训练；如需清除 App 保存的全部本地数据，可以删除「组间」App。健康 App 中由系统管理的数据，需要在 Apple“健康”App 中另行查看或删除。

5. 数据安全

本地训练记录使用 Apple 平台提供的文件保护能力保存。尽管任何技术都无法保证绝对安全，我们会尽量减少所处理的数据，并将处理限制在实现核心功能所必需的范围内。

6. 儿童隐私

「组间」并非专门面向儿童设计。App 不建立用户账号，也不会将个人数据发送给开发者服务器，因此我们不会主动收集儿童的个人资料。

7. 本政策网页

本页面托管于 GitHub Pages。访问本网页时，GitHub 可能按照其自身政策处理标准网络连接信息；该处理与「组间」App 本身无关。详情可查看 GitHub 隐私声明。

8. 政策更新

如果 App 的数据处理方式发生变化，我们会更新本页面并修改顶部的“最后更新日期”。重大变化会在适当情况下通过 App 或版本说明告知用户。
